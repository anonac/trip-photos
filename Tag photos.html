Tag photos

This needs Microsoft Edge or Google Chrome. Right-click this file → Open with → Microsoft Edge.

Choose your site folder (or the photos folder inside it).
Tags are saved to photos/tags.json as you go.

Click a tag to add or remove it.
Type a new one and press Enter.
Ctrl/Shift-click photos to tag several at once.
